# ui-interaction：UI 交互规范与走查

## 交互规范（antd）

- 异步加载：页面初始化拉数据要有 loading 态，回填期间表单不可闪空
- 提交：按钮 loading + 防重复点击；成功/失败都用 `message` 中文提示
- 表单：必填项 `rules` 校验 + 中文提示语；日期用 dayjs，提交转 `YYYY-MM-DD`
- 空态：`GET /api/xxx/latest` 返回 404 = 暂无数据，正常展示空表单，不报错
- 异常：接口失败 `message.error` 提示，页面不白屏、不崩溃
- 导航：新增页面必须同步注册路由 + 菜单，刷新可直达（SPA 兜底）

## 验收走查清单

改动完成后逐项确认：

```
- [ ] 正常路径：操作后 UI 反馈正确（数据/提示/跳转）
- [ ] 加载与提交态可见，重复点击不重复提交
- [ ] 接口失败/断网：有中文提示，页面不崩溃
- [ ] 空数据/首次进入：无报错，展示合理空态
- [ ] 刷新当前路由可直达，菜单高亮正确
- [ ] npm run test:e2e 通过
```
