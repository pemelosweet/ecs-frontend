# 整体布局与视觉风格优化 — 设计文档

日期：2026-07-26
状态：已确认（风格与布局经可视化对比选定，方案经用户批准）

## 背景与目标

现状为 antd 默认观感：深色侧栏 + 默认蓝 `#1677ff` + 阴影卡片，缺乏辨识度。
目标：整体升级为「云控台浅色蓝」风格——安静、专业、描边化的浅色控制台，
不引入新依赖，不改业务逻辑。

## 已确认的方向决策

- 风格方向：**A · 云控台浅色蓝**（可视化对比中从三方向选定）
- 布局结构：**A · 白色侧栏**（现有 Sider 结构精修，保留扩展性）
- 主色：`#2f54eb` 靛蓝
- 签名元素：菱形 ◆ 品牌标 + 选中态浅蓝药丸

## 设计令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| colorPrimary | `#2f54eb` | 主色（按钮、选中态、链接） |
| 页面底色 | `#f5f7fa` | 内容区背景（雾蓝灰） |
| 容器白 | `#ffffff` | 侧栏、页头、卡片 |
| 描边 | `#e5e9f0` | 1px 细边框，替代重阴影 |
| 主文字 | `#0f172a` | 标题、正文 |
| 次文字 | `#64748b` | 说明文字、面包屑、图标 |
| borderRadius | `8` | 全局圆角 |

字体：沿用系统字体栈，不引入 web font。
类型阶梯：页面主标题 20px/600，卡片标题 16px/600，正文 14px，辅助 12px。

## 布局改造（MainLayout.jsx）

1. **侧栏**：去掉 `theme="dark"`，白底 + 右侧 1px 描边；宽度 208；
   选中菜单 = `#eef2ff` 浅蓝底 + 靛蓝字（antd Menu light 主题 token 控制）
2. **Logo 区**：靛蓝 ◆ + 「中后台管理系统」，折叠时只显示 ◆
3. **页头**：白底 + 底部 1px 描边；左侧折叠按钮 + 当前页名；
   右侧静态用户区占位（头像 + 用户名）
4. **内容区**：面包屑弱化为次文字色；内容容器改为 1px 描边卡片
   （白底 + `#e5e9f0` 边框 + 8px 圆角，去掉大阴影）

## 全局与页面统一

- `main.jsx`：ConfigProvider 注入上表全部 token（含 Menu/Layout 组件级 token），
  页面代码不散落硬编码色值
- `index.css`：body 底色改 `#f5f7fa`
- 各页面（首页/表单页/组织信息页/404）：卡片统一为描边风格，标题层级对齐
  类型阶梯；不动表单字段、接口调用、业务逻辑
- 顺带修复：NotFound「返回首页」按钮 `/dashboard` → `/home`

## 明确不做（YAGNI）

- 暗色模式 / 多主题切换
- 动画库或新依赖
- 页面功能与接口变更

## 验收标准

1. `npm test`、`npm run test:e2e`、`npm run build` 全绿
   （e2e 菜单定位用 `getByRole('menuitem')`，侧栏转白不受影响）
2. ui-interaction 走查清单通过（加载态、空态、刷新直达、菜单高亮）
3. 全站唯一实心靛蓝出现在：主按钮、选中菜单、品牌标——其余保持黑白灰
